# AI Video Studio V5 production
Ten 6s scenes, native 1080x1920 60fps. Push triggers a 12s, two-scene preview; manually dispatch full mode after visual approval. Narration defaults off; opt-in Gemini only on a billing-disabled project with free tier confirmed; no automatic API request. Voice lock Zubenelgenubi, original scripted Indonesian text, Whisper word alignment threshold 75%, manual review still needed. No on-camera speaking in this story (off-screen narration); mouth amplitude parameter exists but phoneme/lip-sync not implemented. Scenes use a shared procedural 3D coast and set dressing, one rigged Brachiosaurus, not new dinosaur species or actual footage of Lombok. Character locks preserve mesh identity and materials, experimental sagittal IK gait, not a fully skinned rig or verified natural motion. Procedural PBR-like color/roughness maps and directional shadows, not full baked PBR library or cinematic DOF. Parallel per-scene render (max 10), GLB and scene caches, assembly and MP4 frame/audio/decode checks. Preview and full artifacts on GitHub; no ChatGPT automatic delivery enabled. Previous workflows retained. Model likeness, IK foot slip, environment quality, and final production speed require review. Google AI storyboard module generates drafts, not executable scene recipes; this project uses a curated script.
