# V5 Permanent Character Lock
Master: STICKMAN_001, restored from existing Character Engine V3 SVG. Source paths, colors and joint geometry retained; only root position/viewBox recentered. The original uploaded image is not available in this session. Do not replace this character with the previous yellow hoodie hero. All V5 hero scenes should call characterSVG({frame,fps,motion,expression}) with this fixed ID. The pure frame-based SVG function supports repeatable rendering in Remotion; no time-dependent random changes. Use SVG as transparent overlay for semi-realistic Three.js backgrounds. Full 3D GLB conversion, camera-angle turnaround, IK and audio lip sync are not implemented. This module is an isolated foundation, not an installed full V5 renderer. Test with node video-studio-v5/character-lock/test.mjs. No rendering workflow is launched or changed by this addition.
