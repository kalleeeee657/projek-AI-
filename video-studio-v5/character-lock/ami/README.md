# Ami — Character Lock

Ami (AMI_001) is the approved second character, based on the user-provided character design sheet. Preserve identity, clothing, hair and proportions from the sheet; use semi-3D styling compatible with STICKMAN_001. Smartphone is optional. Reference is saved in ChatGPT under Ami, not included as a binary in this repository. Model, rig, and renderer integration remain to be built. This design lock does not modify the existing STICKMAN_001 asset or launch any rendering workflow.
