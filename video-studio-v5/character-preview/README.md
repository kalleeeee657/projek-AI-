# V5 Character Duo prototype
Procedural 3D meshes and hierarchical articulated joint groups, based on the two approved design-lock descriptions. Original reference sheets remain the visual authority; exact likeness is not established until the preview is approved. This is not a skinned deformable humanoid or GLB rig; limb shapes are separate meshes parented to joints. Fixed palettes, reusable identities, deterministic pose API, blinking, simple wave, walk, talk and Ami phone pose. Walk is not IK foot-planted; dialogue is not lip-synced. Native 1080x1920 60fps six-second silent test, three real stills, software WebGL and shadows. No paid API, no overwrite of previous video or master assets. Visual approval required before integration in Mandalika scene.
