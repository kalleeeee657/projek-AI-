# Google AI Studio integration — V5
Google AI Studio is used to manage Gemini Developer API credentials and test models. This module is a REST client, not the AI Studio website installed into GitHub. Existing GEMINI_API_KEY secret is referenced (never read or printed); current key/tier/model eligibility not yet verified. Check https://aistudio.google.com/ and https://ai.google.dev/gemini-api/docs/pricing before dispatch. API calls are disabled on pushes; only manual workflow dispatch with confirm_free_tier=true permits one request. The confirmation is a user assertion, not a Google billing verification. Use a project with billing disabled to avoid charges; no paid fallback or automatic retry. Model IDs are fixed allowlist and may need update if unavailable. Storyboard drafts validate locked character IDs, total duration, 6–8s scenes, 1080x1920 60fps, and narration length. Voice preview uses existing Zubenelgenubi profile. Output is a draft JSON or raw WAV and metadata; neither automatically modifies renderer or existing video. Subtitle alignment and integration into production remain separate work; no lip-sync, Veo, image API or automatic full video rendering. Offline tests exercise validation and quota guard without network.
