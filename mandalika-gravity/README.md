# Mandalika Gravity
Original procedural stylized cartoon. Scenes 2–6 show different viewpoints or slow-motion illustrations of one hypothetical five-second loss of Earth's gravitational attraction, not a literal 60-second event. No claim that objects automatically rise high. Landmarks are inspired by Lombok, not exact replicas. Voice profile: Gemini Zubenelgenubi with consistent prompt; new narration may vary slightly, audio cached by script. Subtitles preserve script and use Whisper word timestamps with interpolation for unmatched words; not true acoustic forced alignment. Check alignment report and preview frames. No Codex or 9Router connection is required or used. Run via GitHub Actions.
