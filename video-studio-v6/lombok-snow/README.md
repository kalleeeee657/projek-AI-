Original locked hero code copied unchanged. Snow particles, textured snow-like ground, coastal palms and Sade-inspired procedural structures; not geographic replicas, no measured landmarks or accumulation simulation. Preview uses ambient audio and manually timed captions, no Gemini API calls. All other scenes are planned only. Visual realism, NPC animation, and landmark likeness need review. Workflow validates 360 frames per scene and 720 total, actual decode and audio. Previous V5 intact.
